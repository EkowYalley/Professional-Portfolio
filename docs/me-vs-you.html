Me vs. You

A two-player adaptation of Snake built with Python Turtle, with independent controls, scoring, growth, and collision rules.

The build

Two players share one game board: the white snake uses the arrow keys and the green snake uses W, A, S, and D. Food collection grows the active snake, updates its score, and gradually increases game speed.

What I implemented

  • Keyboard event handling for two independent players.
  • Segment-based body growth and movement.
  • Boundary, self, head-to-head, and opponent-body collision detection.
  • A shared food object and persistent on-screen scoreboard.

How to run it

The game uses Python’s standard-library turtle module. Run python Hack.py from a local graphical Python environment; no third-party package is required.

Authorship note: this learning project adapts patterns from classic Snake and online Turtle examples into a two-player version. The repository now states that provenance directly.

Review status and limitations

The source passes Python syntax compilation. Because graphical state and the continuous game loop are tightly coupled, the collision behavior is not covered by automated tests. A stronger next version would extract pure game-state functions, add restart/pause controls, and test collision outcomes separately from the interface.
