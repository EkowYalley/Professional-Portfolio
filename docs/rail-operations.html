Rail Operations Data Exploration

Exploratory work comparing rail-car behavior across operating conditions and track segments, with the public evidence boundary stated clearly.

Project context

As Data Lead on an MxV Rail team project from August through December 2025, I analyzed months of train-run data using Python and Orange and created visual material for team discussions.

Disclosure: the underlying dataset and analysis code are not public. This page describes the work at a high level and does not substitute for a reproducible repository.

Analytical approach

  • Compared observations across operating conditions and track segments.
  • Explored differences in rail-car behavior and surfaced patterns for review.
  • Translated findings into visualizations designed for discussion with the project team.

What can be claimed

The work demonstrates exploratory analysis, visual communication, and leadership in a team setting. It does not establish that a detected pattern caused a safety outcome, prevented a failure, or changed a maintenance schedule.

What would strengthen the evidence

  • A shareable, anonymized data dictionary or synthetic dataset.
  • A documented notebook showing representative transformations and charts.
  • Named validation checks and a record of which recommendations were adopted.
  • Measured operational outcomes tied to the analysis, if they exist and can be disclosed.
