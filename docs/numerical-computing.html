Numerical Computing Experiments

A set of learning projects around power iteration, just-in-time compilation, Monte Carlo simulation, and responsible performance measurement.

The analytical idea

Power iteration estimates the dominant eigenvalue and eigenvector of a matrix—an operation connected to methods such as principal component analysis. The repositories explore NumPy and Numba implementations plus batch execution through Slurm.

What the review found

The original timing logs were not suitable for a speedup claim: serial and compiled runs used different matrix dimensions, and the Numba log reported that its TBB threading layer was disabled.

Correction made: the main repository now includes a controlled benchmark that gives both implementations the same seeded matrix, starting vector, convergence tolerance, and iteration limit. It warms up compilation, reports median timing, and validates both estimates against NumPy’s symmetric eigensolver.

Companion Monte Carlo exercise

A second small repository estimates pi from one million random samples using Numba’s nopython mode. Its recorded Slurm run produced 3.140052. That is a technique demonstration, not a controlled performance benchmark.

What can be concluded

The work demonstrates numerical-method implementation, compiled Python loops, batch-computing exposure, and—after review—better benchmark design. It does not currently support a general claim that Numba or parallel execution is faster for every workload.
